# Sweet Moments Showcase

Build a complete, premium-looking, responsive bakery website for a real local business called:

"DELICIOUS Cake & Bakery"

"BY TANVI"

Business type:

Local Cake Shop & Bakery

Business address:

140, Sardar Rd, Shyampark Society, Krishnanagar, Ahmedabad, Gujarat 382345

IMPORTANT PROJECT GOAL:

This is NOT supposed to be a huge e-commerce website or an enterprise bakery platform.

Create a beautiful, modern, affordable-looking-but-premium local bakery website that would realistically be suitable for a small Ahmedabad cake shop.

The website should feel:

- Elegant

- Warm

- Premium

- Delicious

- Celebration-focused

- Trustworthy

- Modern

- Friendly

- Visually impressive

- Mobile-first

The website should make a customer immediately want to:

1. Browse cakes

2. See birthday/celebration designs

3. Contact the bakery

4. Order a cake through WhatsApp

5. Visit the shop

Do NOT over-engineer the project.

Do NOT create an admin dashboard.

Do NOT create authentication.

Do NOT create payment processing.

Do NOT create a complicated backend.

Do NOT create fake customer reviews.

Do NOT create fake statistics.

Do NOT claim delivery services unless clearly presented as "Ask us about delivery".

This is primarily a premium business showcase + WhatsApp enquiry website.
